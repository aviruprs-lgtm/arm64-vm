QEMU virt · aarch64 · Alpine 3.24

A virtual ARM64 machine that boots to a desktop

Not a container and not an emulated shell — a complete aarch64 computer: a Linux 6.18 kernel, a real ext4 root on a virtio block device, working networking, an SSH daemon, and an X11 session that comes up on its own. It runs under QEMU's TCG translator, so it boots on any x86-64 host with no ARM hardware and no KVM.

02 — the desktop

It really does boot to a GUI

Nothing is configured by hand. /etc/inittab respawns the session on tty1, which runs xinit; Xorg finds the virtio-gpu DRM device and picks its built-in modesetting driver; /root/.xinitrc paints the root window and starts twm and xterm.

VIEW IT

Any VNC client

Connect to 127.0.0.1:5900. Keyboard and mouse arrive as USB HID events.

TUNE IT

Mode, terminals, WMs

xrandr -s 1024x768 changes mode. apk add icewm then edit /root/.xinitrc.
