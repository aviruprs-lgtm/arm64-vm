01 — how it boots

Two stages, like a real distribution

The kernel has CONFIG_VIRTIO_BLK=m and CONFIG_EXT4_FS=m, so it cannot mount its own root. The boot is staged.

STAGE 1

Initramfs

BusyBox plus the eight modules needed. Loads virtio_pci, virtio_blk and ext4, then waits for /dev/vda.

→
STAGE 2

switch_root

Mounts the ext4 root read-write and hands over to /sbin/init.

→
STAGE 3

Userspace

vm-rc remounts rw, runs DHCP, loads the GPU and USB HID drivers, starts sshd — then getty and X.

Kernel detail. Alpine ships vmlinuz-virt as a PE32+ EFI-stub wrapping a gzip payload. Handed straight to the kernel loader, QEMU enters the stub and hangs with no output. The build extracts the inner Image and boots that.
02 — run it

Boot it yourself

QEMU 6.0 or newer with aarch64 system emulation is the only requirement. The release carries the machine as two parts; join them back into one archive, unpack it, and start the launcher. Full commands are in the repository README.

STEP 1

Download

Grab both parts from the latest release and concatenate them in order. The result is a 102 MB xz archive.

STEP 2

Unpack and run

Extract the archive and start run.sh. Ctrl-A X quits QEMU; the serial console is on the terminal you started it from.

DESKTOP

VNC on 5900

Point any VNC viewer at 127.0.0.1:5900. The X session starts on its own a few seconds after boot.

SHELL

SSH on 2222

Connect to 127.0.0.1:2222 as root, password arm64vm. The same login works on the serial console.

TUNING

Environment

  • MEM guest RAM in MiB (default 448)
  • SMP vCPUs (default 2)
  • TB TCG translation cache in MiB
  • SSH_PORT, VNC_DISPLAY port remapping
